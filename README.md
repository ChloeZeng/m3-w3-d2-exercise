# m3-w2-d2-exercise
WEB 602 Back-end

In this exercise, I learned how Sass (SCSS) extends the functionality of regular CSS. By writing styles in .scss files and compiling them into .css using the command npm run scss, I was able to apply dynamic and organized styling to my webpage. I practiced using variables (e.g., $color-primary) to maintain consistent colors and fonts, and learned how @import helps modularize and reuse style code. Compared to plain CSS, SCSS makes styling more efficient, maintainable, and easier to scale for larger projects.
